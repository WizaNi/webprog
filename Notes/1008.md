# DOM

1. Lekero elemek
    - `document.getElementBy("id");`
    - `document.getElementsByClassName("class");`
    - `document.gerElementByTagName("tag");`
    - `document.querySelector("cssJelolo");` - **az első elem**, CSS szelektor alapjan
    - `document.querySelectorAll("cssJelolo");` - **az összes elem**, CSS szelektor alapjan
2. Letrehozas
    - `document.createElement("tag");`
3. Osszefuzes
    - `append(tag);` - szuloelem **vegehez** hozza fuzi
    - `prepend(tag);` - szuloelem **elejehez** hozza fuzi
    - `after()/betfore()` - nem hasznaljuk

---

## DOM node

1. **Element**: *h1, p, a*
2. **Root**: *Document*
3. **Attribute**: *src, href, alt*
4. **Text**: *Lorem5*

---

## Attributumok es szovegek megadasa

- `.textContent/.innerText` - **nem ajanlott**, nem biztonsagos
- `.className` - ajanlott, nem clean
  - `button.className = "btn btn-info"`
- `.classList.add()` - ajanlott, clean
  - `button.classList.add("btn", "btn-info")`
- `.setAttribute(mit, mire)`
  - `button.setAttribute("type", "button")`

---

## Fuggvenyek

1. `function name(*parameter*){}`
2. `(*parameter*)=>{}`
3. Valtozos fuggvenyek:
   - `const name = (*parameter*)=>{}  --> name(*parameter*)` - anonim, a valtozo nevet veszi fel
   - `const name = function(*parameter*){} --> name(*parameter*)` - anonim, a valtozo nevet veszi fel
